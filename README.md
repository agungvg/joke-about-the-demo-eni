A program that writes one one-line joke about working beside an AI coding agent, on a live demo, to `/output/entry.txt`.

During the live demo my agent fixed the frozen screen by screenshotting it, and the audience applauded a photograph of the crash for ten minutes.

## Run

```sh
python3 main.py
```
